# Before publishing on GitHub

- [ ] Review every notebook for secrets, emails, account IDs, workspace links and internal data.
- [ ] Confirm the dataset is shareable; this package does not include it.
- [ ] Replace hard-coded Unity Catalog and Volume paths where appropriate.
- [ ] Check that any figures, reported metrics and business claims match notebook outputs.
- [ ] Keep the original ZIP private as a backup.
- [ ] Make the repository public only after reviewing its contents.
- [ ] Add a project screenshot or architecture diagram if desired.
- [ ] Consider a license after deciding how others may reuse the code.
